# Siebel-Workspace-Delivery-tool
Siebel Workspace Delivery Tool which

before we use this tool we need to make few changes as per your Siebel Tools paths

1. HTA_Param.vbs
   a. in this file update your Siebel installable paths and Credentials.
   b. Make sure your path folder names should not have spaces.

2. WS_Delivery_Tool.HTA
     a. in this at 'LoadParams()' function update your HTA_Params.vbs full path.
     b. in this path make sure this WS_Delivery_Tool.HTA is placed and create a desktop shortcut.

Done. your tool is ready to use.
